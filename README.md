# Saudi Arabia Travel and Tourism Platform

A multi-page responsive travel website designed to showcase prominent landmarks, cultural destinations, and historical sites across Saudi Arabia.

**Live Demo:** https://saudi-travel.vercel.app

---

## Overview

This repository provides an interactive web portal for exploring tourism destinations throughout Saudi Arabia. Built entirely with core web technologies, the platform delivers visual showcases, modular pages, and responsive layouts without external UI frameworks.

---

## Key Features

- **Multi-Page Structure:** Dedicated pages for the primary landing view, destinations showcase, and contextual information.
- **Destination Highlights:** Structured presentations of notable cultural, heritage, and metropolitan locations.
- **Cross-Device Responsiveness:** Fluid layouts built to display consistently across desktop, tablet, and mobile screens.
- **Native Web Performance:** Lightweight build using standard HTML5, CSS3, and modern JavaScript for minimal overhead and fast load times.

---

## Tech Stack

- **HTML5:** Semantic document markup across site pages (index.html, Destinations.html, About.html)
- **CSS3:** Modular stylesheets (style_1.css, style_2.css, style_3.css) using responsive layout techniques
- **JavaScript (ES6+):** Client-side scripting for interactive elements and interface logic (script.js)
- **Vercel:** Production hosting and deployment pipeline

## Getting Started

### Prerequisites

A modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge).

### Local Setup

1. Clone the repository:
   git clone https://github.com/Usman1487/Saudi-Travel.git
   cd Saudi-Travel

2. Run the site locally:
   Open index.html directly in your web browser, or serve it using the VS Code Live Server extension.
